# Analyse du dataset Wine Quality (R)

Analyse statistique et graphique du dataset Wine Quality réalisée avec R.

## Contenu du projet
1. Introduction au dataset et à ses variables
2. Démarche de préparation des données
3. Analyses statistiques et graphiques
4. Conclusion et interprétation des résultats

## Technologies
- R
- RStudio

## Fichiers
- `projetWine.R` : script d'analyse
- `winequality.csv` : jeu de données

## Exécution
1. Télécharger le dépôt
2. Ouvrir le script dans RStudio
3. Vérifier que le fichier de données est dans le même dossier
4. Exécuter le script
